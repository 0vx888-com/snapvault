如何读取已收到的消息
  1. 在收件箱连接持有该容器的钱包，选择 X Layer 主网。
  2. 按客户端提示在本机派生解密密钥。登录及派生签名不花 gas；只有你确认后才操作。
  3. 选择已有容器，刷新历史收件箱即可；查看旧消息无需重新付款或发信，也无需重新发布公钥。
  4. 打开 SnapVault 查看链接时开始计时。链接含查看凭证，请勿复制给他人。平台仍负责内容交付，无法阻止截图。
无容器用户直接在站内已购订单查看；不会要求你另开容器。
已有容器时填写电路合约和编号。有可用公钥时付款后自动发送到官方收件箱；没有容器可使用普通交付。

关于这个预览
这是本地体验版。你可以切换演示身份、私聊与群聊、设置阅后即焚，并体验图片发布、模拟购买和解密。
这些记录保存在当前浏览器。免费聊天尚未接入真实多人服务；钱包登录、免容器交付和公共图片存储仍在开发。当前不会扣款，也不会请求你的钱包签名。
正式产品的付款与分账使用 X Layer，前端发布到 DeWEB。图片存储将单独接入，尚未上传真实内容到 IPFS。
阅后即焚是限时展示，无法阻止截图或收回已保存的内容。
